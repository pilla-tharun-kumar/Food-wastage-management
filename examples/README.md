# Demo scanner code

The seeded tomato product uses the exact barcode/QR value **8901000000011**. Scan the included `demo-tomatoes-qr.png` through **Scan barcode / QR → Scan an Image File**, or type that value in the lookup field. The app finds the existing product's batches; scanning does not create or modify inventory until you save a subsequent stock action.

The image is generated for this project's sample data; it is not a commercial product identifier guarantee.
